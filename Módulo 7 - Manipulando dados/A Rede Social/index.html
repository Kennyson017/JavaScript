Resumo do Projeto

Este projeto consiste em criar um feed de postagens para uma rede social, inspirado no modelo do Twitter.

No sistema, o usuário poderá escrever novas postagens através de um formulário fixo no topo da página. As postagens serão exibidas da mais recente para a mais antiga, contendo o nome de usuário, avatar, texto, uma imagem aleatória de gatinhos (fornecida pela API The Cat API) e um botão de curtir.

O objetivo do trabalho é praticar a criação dinâmica de conteúdo no DOM, manipulação de arrays de objetos, integração com API externa e interação de eventos de clique.
